# Open Roberta export samples

Programs exported from Open Roberta Lab (mBot 2). `npm run or:codegen` imports each one
into the sim's blocks, checks no block is lost, and generates code. Add a file here
whenever a new kind of program should be covered (the more blocks, the better).

```
openroberta/    programs exported from Open Roberta Lab (Editar → Exportar programa)
```

| File | Covers |
|------|--------|
| `01-simples` | display text, wait for key A, tone, drive/turn for, drive, wait for ultrasonic < 15, stop, LEDs, repeat, wait ms |

The sim also opens these files directly (**Carregar**).
